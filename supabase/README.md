# إعداد Supabase

1. أنشئ مشروع Supabase جديداً.
2. نفّذ ملف schema.sql من SQL Editor.
3. أنشئ Storage buckets لصور الكادر وأرشيف الجلسات ومرفقات الدردشة، ثم أضف سياسات التخزين المناسبة قبل تفعيل الرفع.
4. اضبط مزودات تسجيل الدخول وروابط إعادة التوجيه.
5. أنشئ حساب الإدارة الأول، ثم غيّر role إلى admin يدوياً من لوحة SQL بعد التحقق من UUID.
6. استخدم رابط المشروع ومفتاح publishable/anon فقط في تطبيق الهاتف. لا تضع service-role key داخل التطبيق.

المخطط أولي ويحتاج مراجعة أمنية واختبار سياسات RLS والتخزين قبل بيانات الإنتاج.
