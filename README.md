# AL SHEIKHA MASSAGE CENTER

مشروع مركز **الشيخة** — نواة أولية لتطبيقين Android مستقلين يتشاركان خلفية واحدة.

## المستودع
- `admin_app/`: تطبيق الإدارة.
- `client_app/`: تطبيق العملاء.
- `supabase/schema.sql`: مخطط أولي لقاعدة البيانات المشتركة.
- `.github/workflows/android-build.yml`: سير بناء APK للتطبيقين.

## التقنية والتصميم
Flutter، واجهات عربية RTL، ألوان هادئة وردي ترابي وموف وكريمي، ودعم الوضعين الفاتح والداكن. الخلفية المقترحة Supabase.

## نطاق المنتج المتفق عليه
إدارة الكادر (حتى 10 صور لكل عضو، الاسم والعمر والعنوان ووجود مكان وحالة التوفر وسعر الساعة والليلة بالدينار العراقي)، أرشيف الجلسات (حتى 10 صور وتاريخ وربط العضو)، حتى 7 بانرات مع ربطها بعضو أو جلسة، البحث والمفضلة، الحجوزات، ومحادثات متعددة بين العميل والإدارة مع مشاركة ملف العضو وتسجيل حجز من المحادثة.

لا يتضمن النطاق كوبونات أو خصومات أو أنواع جلسات.

## حالة هذه الدفعة
هذه **نواة تأسيسية وليست تطبيقاً إنتاجياً مكتملاً**. تتضمن هيكل Flutter أولياً ومخطط SQL أولياً وسير بناء APK. لم يتم بعد ربط مشروع Supabase فعلي، أو تنفيذ المصادقة والرفع والحجز والدردشة بالكامل، أو إصدار APK موقع.

## البناء
يشغّل GitHub Actions عند الدفع إلى `main` أو يدوياً. ينشئ مشروع Android داخل كل تطبيق ثم يبني APK ويرفعه كـ workflow artifact.

## أمان
لا تضع مفتاح Supabase service-role داخل تطبيق الهاتف. راجع سياسات RLS وسياسات التخزين واختبرها قبل استخدام بيانات حقيقية.
