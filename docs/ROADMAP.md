# خارطة تنفيذ مشروع الشيخة

## الدفعة الحالية: التأسيس
- تطبيق إدارة مستقل وتطبيق عملاء مستقل.
- هوية لونية مشتركة، العربية RTL، الوضع الفاتح والداكن.
- مخطط أولي لقاعدة البيانات وسير بناء APK.

## الدفعات التالية
1. إنشاء مشروع Supabase فعلي وربط التطبيقين بمفاتيح آمنة.
2. إكمال المصادقة والأدوار ومراجعة سياسات RLS والتخزين.
3. إدارة الكادر: البيانات، حد 10 صور، التوفر والأسعار بالدينار العراقي.
4. أرشيف الجلسات: التاريخ، الصور، وربط كل جلسة بعضو.
5. البانرات: حد أقصى 7 وربط كل بانر بعضو أو جلسة.
6. تطبيق العميل: البحث والمفضلة وملفات الكادر والحجوزات.
7. الدردشة: محادثات منفصلة مع الإدارة، المرفقات ومشاركة ملف العضو، وإنشاء حجز من المحادثة.
8. الاختبار على أجهزة Android وإصدار APK موقع.

## ملاحظة
الميزات أعلاه نطاق مستهدف وليست كلها منفذة في هذه الدفعة. لا يتضمن النطاق كوبونات أو خصومات أو أنواع جلسات.
